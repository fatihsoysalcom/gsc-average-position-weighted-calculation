# GSC Average Position Weighted Calculation

This example demonstrates how Google Search Console's simple average position can be misleading and how a weighted average position, or filtering by top ranks, can provide more actionable insights. It simulates GSC-like data for search queries and calculates different average position metrics to highlight the 'mathematical flaw' discussed in the article. The weighted average gives more importance to queries with higher impressions, offering a more realistic view of effective visibility.

## Language

`python`

## How to Run

Save the code as `main.py` and run from your terminal:
`python main.py`
